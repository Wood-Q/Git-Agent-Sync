# Agent Sync

Browse and restore Agent-Sync sessions from the VS Code SCM view.

This extension calls the `agent-sync` CLI from your PATH by default. If the CLI is installed somewhere else, set `agentSync.cliPath` to the command or absolute path.

Publishing metadata:

- Extension package: `agent-sync-vscode`
- Version: `0.1.0`
- Repository: `https://github.com/Wood-Q/Git-Agent-Sync`
